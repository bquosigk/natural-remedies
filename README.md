# Traditional & Natural Home Remedies (static site)

Open `index.html` in any browser; no server or build step needed.
Deploy as-is: drag this folder onto Netlify, or push it to a GitHub repo and enable GitHub Pages (root folder).

- `assets/search-index.js` holds the search data (generated from the guide); `assets/search.js` is a small dependency-free search.
- Regenerate pages from the guide data with `python3 build/build_site.py` (in the parent project).

Not medical advice. See the footer disclaimer on every page.
